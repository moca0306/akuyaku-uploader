プライバシーポリシー

akuyaku-uploader（以下「本ツール」）は、運営者が自分の YouTube チャンネルへ動画・サムネイル・説明文などを投稿するためだけに使う個人用の道具です。

  • 本ツールは YouTube Data API を通じて、運営者が許可したチャンネルへの投稿と、投稿した動画の状態の確認だけを行います。
  • 取得した許可の情報は運営者のコンピューターの中だけに保存し、投稿の目的以外には使いません。
  • 取得した情報を第三者へ渡したり、販売したりしません。
  • 許可は Google アカウントの設定（https://myaccount.google.com/permissions）からいつでも取り消せます。

Privacy Policy

akuyaku-uploader ("the tool") is a private tool used only by its operator to upload videos, thumbnails and descriptions to the operator's own YouTube channels.

  • The tool uses the YouTube Data API only to upload to channels the operator has authorized and to check the status of uploaded videos.
  • Authorization data is stored only on the operator's own computer and is used only for uploading.
  • No data is shared with or sold to third parties.
  • Access can be revoked at any time from your Google Account settings (https://myaccount.google.com/permissions).

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
